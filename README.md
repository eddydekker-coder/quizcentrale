# Quizcentrale

Beheer-app voor De Blauwe Banaan Pubquiz: quizavonden, locaties, aanmeldingen, scores, stand, quizmaster-script en vragenbank.

De app is één HTML-bestand (`index.html`) dat via GitHub Pages wordt gehost. Gegevens en geüploade bladen staan in Supabase (project *quizcentrale*) en zijn alleen toegankelijk na inloggen met een uitgenodigd e-mailadres.
